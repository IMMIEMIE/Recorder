# 声笺 0.7.0

安卓新增面对面双人互译。两个人可以共用一部手机，各自说自己的语言，在自己这一侧看到对方的译文。普通转译也支持在录制中切换目标语言。[功能说明与实现](https://github.com/IMMIEMIE/Recorder/pull/36)

## 安卓使用方法

- 打开主界面的「双人对话」，选择双方语言后点「开始」。上半屏默认朝向对方，中间的操作栏可切换为同向阅读、互换语言或退出对话。
- 双方共用一个麦克风。双路云端会话分别译成两种目标语言，音频输入用量约为普通模式的两倍。语种无法确定时，两侧都显示原文并标记「语种未识别」。
- 想听译音时，在对话的更多菜单中开启。应用在识别说话方后播放给对方的译音。使用扬声器时，播报期间会将上行音频替换为静音，这段时间的插话也会被静音；戴耳机可继续收音。
- 普通模式下，点目标语言即可在录制中换语种。当前句沿用原目标语言，后续字幕会标出切换位置。会话和导出文件保留说话方、逐句语言及切换标记。

## 安装

| 平台 | 安装包 | 系统要求 |
| --- | --- | --- |
| Android | `Recorder-0.7.0-android.apk` | Android 8.0 或更新，正式发行签名，支持从 0.6.0 正式版覆盖升级。 |
| macOS | `Recorder-0.7.0-arm64.dmg` | Apple Silicon、macOS 14 或更新。随本次联合发布更新版本号，采用 ad-hoc 签名，尚未经 Apple 公证。 |

两份安装包均附 SHA-256 校验文件。此前安装的「声笺 · 双向测试」预览版可与正式版并存，两者的配置和会话各自保存。
