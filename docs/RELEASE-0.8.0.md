# 声笺 0.8.0

本版更新了 Android 实时字幕和双人对话界面。macOS 和 Android 现在都可以在应用内切换九种界面语言。

## Android 界面

- 录制时，正在识别的一句会单独突出显示，点按已定稿的字幕即可复制。向上阅读后，可点「回到最新」返回当前字幕。
- 双人对话分屏用大字显示对方的译文，自己的原文靠右显示。两人之间的控制栏可以开关译音，也可以旋转对方一侧的画面。
- 会话侧栏支持按标题搜索，可从每条会话旁的菜单管理记录。导出时可先预览前五行，再保存、分享或复制全文。[Android 界面改动](https://github.com/IMMIEMIE/Recorder/pull/39)

## 界面语言

两端都支持简体中文、繁体中文、英语、日语、韩语、西班牙语、法语、德语和泰米尔语。默认跟随系统，也可在 macOS 的「设置 → 转写 → 界面语言」或 Android 的「设置 → 界面语言」手动选择。Android 13 及以上还可通过系统的应用语言设置切换。

菜单、录制状态和错误提示会使用所选界面语言。识别语言和翻译目标语言可独立设置。[多语言改动](https://github.com/IMMIEMIE/Recorder/pull/40)

## 安装

| 平台 | 安装包 | 系统要求 |
| --- | --- | --- |
| Android | `Recorder-0.8.0-android.apk` | Android 8.0 或更新，使用正式发行签名。 |
| macOS | `Recorder-0.8.0-arm64.dmg` | Apple Silicon，macOS 14 或更新。使用 ad-hoc 签名，尚未经 Apple 公证。 |

每份安装包均附有 SHA-256 校验文件。
