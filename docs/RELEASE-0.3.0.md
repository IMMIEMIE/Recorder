# 声笺 0.3.0

- 主窗口和菜单栏新增「另存为…」，通过原生保存面板导出已定稿文本为 UTF-8 TXT。打开面板时固定文本快照。
- 新增 AI 提问面板：摘要、翻译（默认简体中文）、自定义问题，可编辑待发送原文。
- 支持 DeepSeek、OpenAI 和兼容 Chat Completions 流式接口；接口地址和模型可自定义，API Key 按接口地址保存在系统钥匙串。
- 流式结果可停止、复制和另存为；中断保留已收到的内容。不会自动发送，文字仅在当前会话内保留。
- 模型权重仍由用户独立下载，安装包不包含模型，更新复用原有缓存。

## 验证

- Swift release 编译通过，无警告；原有 18 项 Python 单元测试通过。
- scripts/test_ai.sh 使用合成文本和本地模拟服务，验证接口校验、凭据隔离、请求编码、输入长度、UTF-8 分片 SSE、HTTP 错误、拒绝重定向、错误/截断数据、长度终止和取消。
- 使用真实 SwiftUI 面板测试载体检查翻译目标语言、AI 设置布局、原生保存面板；已实际保存并核对中英文 TXT 内容。
- 未使用真实 API Key 调用付费服务，未验证服务商实际翻译质量。初次使用需用户填写有效 Key 和有权限的模型。
- 安装包为本机临时签名，未公证；无需重下已有识别模型。
