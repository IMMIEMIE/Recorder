# 声笺 0.5.0

macOS 版与安卓版首次一起发布，版本号统一为 0.5.0。两端都新增了会话记录：像聊天应用一样在侧栏列出每次对话，可以继续录制、重命名、删除，并导出为 TXT 或 Markdown。

| 下载 | 平台 |
| --- | --- |
| `Recorder-0.5.0-arm64.dmg` | macOS 14 或更新，仅 Apple Silicon |
| `Recorder-0.5.0-android.apk` | Android 8.0（API 26）或更新 |

每个文件都附有 `.sha256` 校验值。

## 会话记录与导出（macOS + 安卓）

- 侧栏列出全部会话，按「今天 / 昨天 / 7 天内 / 更早」分组，最近更新的在前；正在录制的会话有标记。macOS 在窗口左侧，安卓手机从左侧抽屉打开，平板和宽屏常驻显示。
- 「新建会话」开始一段新的记录；在历史会话上点「继续录制」会接在原内容后面，导出时标出「继续录制」的时间。
- 录制中可以翻看其他会话，新内容仍写入正在录制的那一个。会话可以重命名；删除和「清空全部会话」都需要确认，录制中的会话不能删除。
- 导出：TXT 或 Markdown，内容可选双语、仅原文、仅译文。macOS 用保存对话框（替代原来的「文本另存为」，菜单项改为「导出会话」）；安卓可以分享给其他应用、保存到文件或复制，不需要存储权限。同一会话在两端导出的内容完全一致。
- macOS 的会话覆盖所有转写方式：本地识别、API 识别、WebSocket 流式识别和云端 LiveTranslate。

### 隐私规则的变化

此前声笺不保存任何文字历史。从 0.5.0 起：

- **录音、译音和识别中的文字从不保存**，这一点不变。
- **定稿的原文和译文默认按会话保存在本机**：macOS 在 `~/Library/Application Support/LocalRecorder/sessions/`，安卓在应用私有目录。会话内容不会上传，安卓也不会进入系统备份或换机迁移。
- 不需要时可在设置中关闭「保存会话记录」：关闭后不再写入，已有会话仍可查看、导出和删除。

## macOS

- **会话记录与导出**，见上文。设置里新增「会话记录」页。
- **字幕悬浮窗改为视频字幕样式**：只显示最新 1–3 行文字（默认 2 行），每行带半透明底条，也可以只显示带阴影的文字；窗口贴着屏幕底部居中、随文字向上伸展，占用尽量少的屏幕。选中字幕窗后可用方向键移动（Shift 每次 40 pt，Option 每次 1 pt），也可以拖动；字号、行数、背景等在右键菜单中设置，位置会被记住。
- **转写区阅读位置**：只有停在底部时才自动跟随新内容；往上翻阅时位置保持不动，出现「回到底部 / 有新内容」按钮（Command + ↓）。
- **本地 Hy-SimulMT 同传暂不包含**：这个实验性的离线同传模式（腾讯 Hy-SimulMT，约 19.75 GB 模型）已经开发完成，但本次构建的推理程序还没有重新通过真机验证，所以 0.5.0 中这个入口保持关闭，会在之后的版本中提供。云端 LiveTranslate 不受影响。
- 从旧版本升级：已下载的模型和设置直接沿用，无需重新下载。

安装：把「声笺.app」拖进「应用程序」。此版本使用临时签名，没有经过 Apple 公证，首次打开如被拦截，请在「系统设置 → 隐私与安全性」中允许。

## 安卓（首个公开版本）

声笺安卓版只做一件事：通过云端 Qwen3.8 LiveTranslate（`qwen3.8-livetranslate-flash-realtime`）实时转写并翻译麦克风语音。没有本地模型，需要你自己的 LiveTranslate API Key。

- 原文与译文同时实时显示；字幕固定在底部，长句增长时始终看得到最新的字，往回翻阅时不会被拉回。
- 按下「开始」就可以说话：连接建立前说的话（最近 5 秒）会在连接就绪后先发送。
- 8 种目标语言：中文、English、日本語、한국어、Français、Deutsch、Español、Русский。
- 可选播放译音（边说边播，或每句定稿后再播）。外放且没戴耳机时自动启用回声消除并提示；可选用蓝牙耳机麦克风。
- 断线、Wi‑Fi 与移动数据切换后自动重连，已有字幕保留并标出断点；网络较慢时会提示。
- 录音期间在通知栏显示最新译文，可从通知栏停止；来电或其他应用占用麦克风时自动停止并保留文字。
- API Key 用 Android Keystore 加密保存在本机，不参与备份。
- 会话记录与导出，见上文。

安装：下载 APK 后在手机上打开，按提示允许「安装未知应用」。首次使用在「设置」中填写服务地址（默认 `wss://maas.qianwenaiapi.com/api-ws/v1/realtime`）和 API Key，可以先点「测试连接」。开始翻译后麦克风音频会持续发送到所配置的服务，可能产生服务费用。

## 不包含在本次发布中

Windows 版本是单独的移植，按各自的版本号发布，不属于 0.5.0。

## 验证

- 两端的会话导出都与同一套参考夹具逐字节比对（`docs/SESSIONS.md`、`tests/fixtures/session_export/`），另有约 90 个 Unicode 边界用例（空白、数字、文件名字符等），macOS 测试中自动比对，安卓在发布前人工核对一致。
- macOS：会话、LiveTranslate、音频输入和流式识别测试通过；本地识别、API 识别和流式识别下的会话保存只经过代码审阅。
- 安卓：协议、会话状态机、会话存储和导出共 33 项 JVM 测试通过；CI 编译并检查 release APK（签名、10 MB 体积上限）。
- 尚未完成：安卓真机与真实 API Key 的冒烟测试（清单见 `docs/VALIDATION.md`）；两端新界面的人工点测。
