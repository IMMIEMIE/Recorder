# 声笺 0.3.1

AI 服务配置移至原有设置窗口的「AI 服务」页，提问面板不再提供配置编辑。

每个规范化后的 Base URL 对应独立 JSON 文件，记录 Base URL 和模型 ID；API Key 按 Base URL 保存在钥匙串。文件位于 ~/Library/Application Support/LocalRecorder/AIProfiles，文件名是地址的 SHA-256。相同地址覆盖更新，不同地址独立保存。支持新增、选择、保存并使用、删除配置；当前选择跨重启保留。修改地址保存会创建/更新目标地址配置，原地址配置仍保留。

Base URL 自动追加 /chat/completions；支持输入旧完整地址并自动规范化。旧版单一配置首次自动迁移。

验证：release 构建；本地模拟流式 API 回归；地址规范化、两份独立配置、更新覆盖、重新加载及独立删除测试。尚未用真实付费 API Key 验证服务商响应。

本次新版 UI 启动被自动审批拦截（本地临时签名需即时确认），未完成运行时界面检查；构建、模拟服务与文件持久化测试已通过。
