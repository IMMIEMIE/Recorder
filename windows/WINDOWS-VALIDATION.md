# Windows x64 预览版验证

## 0.6.12 外观模式（2026-11-05）

AppSettings.Appearance 默认 system，旧配置缺少字段或无效值采用跟随系统。设置的公共外观页可单独保存并应用，无需模型加载；主窗口关闭设置后同步偏好，避免后续保存覆盖。Theme 统一浅色/深色配色，读取 Windows AppsUseLightTheme，并将系统通知合并后调度到 UI 线程；x64 使用 .NET 10 原生颜色模式配合应用自绘颜色及标题栏。主窗口、设置、AI/服务管理和菜单同步更新，正文重新着色时保留选择、滚动及跟随状态，隐藏的设置页重新挂载时应用当前颜色。

本轮仅编译打包 x64 标准安装包、标准便携包和 CPU 精简便携包。未运行自动测试、实际模型、应用或界面验证；默认系统外观、运行中系统切换、手动选择及重启记忆、长转录阅读位置由用户实际使用确认。

## 0.6.11 时间戳排版（2026-11-04）

时间戳复用原文字体，采用首行左缩进 0、正向悬挂缩进及正文制表位，修正旧版负缩进造成的续行左移。显式换行及译文使用相同正文列；列宽按字体度量、DPI 和分钟位数计算，变化时重新排版。仅编译打包，未运行测试或界面验证，待用户确认实际显示。

## 0.6.10 本地智能定句（2026-11-04）

本地 smart 改为说话 / 候选停顿状态：句尾已被最新识别覆盖且有可靠句末标点时按 SmartSentenceSilenceMs（默认 600）定稿，否则按 SmartFallbackSilenceMs（默认 1500）收尾。300 ms 停顿时缺少句尾覆盖则安排一次额外预览，复用后端最新槽；句段、起点、版本和最后语音位置共同过滤迟到结果。删除本地模式的两次文本相等要求，保留固定与 HTTP API 旧策略，云端流式不经过本地分段。设置保存/加载及校验接通新字段；旧配置缺失时采用默认值。

仅编译打包 x64 标准安装包、标准便携包及 CPU 便携包；未运行自动测试、实际模型、界面验证或性能基准。待用户实测：完整句短停顿、半句话长停顿、候选后续说、英文缩写/小数/引号、慢识别与翻译并行、参数下一会话生效、固定模式、手动停止收尾。停顿阈值不代表文字输出延迟保证。

## 0.6.9 本地译文预览（2026-11-04）

增加最新原文预览的本地翻译队列与 translation_preview 事件。ASR 预览任务可与独立翻译进程重叠运行，final/load/stop 等队列任务等待 ASR 预览结束；定稿译文优先于预览，只有最新待处理预览保留。当前同句生成可完成，UI 按句段及已显示译文来源版本阻止旧结果回退；新句、定稿、停止和设置变化会清除预览。主窗口与悬浮字幕显示预览，历史/导出及翻译上下文仅保留定稿结果；千问流式识别的 partial 也接入本地翻译。仅编译打包，未运行测试、真实模型、UI 验证或性能基准，待用户亲自使用反馈。

## 0.6.8 菜单生命周期（2026-10-31）

用户反馈点击“重播译音”出现 ContextMenuStrip 已释放异常。代码定位为菜单 Closed 事件同步 Dispose，而 WinForms 的 SetVisibleCore 在 OnClosed 后仍访问菜单。重播译音及翻译菜单改为主窗口持有的常驻组件，打开前先完成关闭，再释放旧项目并重新生成内容；主窗口 Dispose 时统一释放菜单，托盘菜单也纳入组件容器。移除 x64 和共享 x86 翻译菜单的同类 Closed/Dispose 路径。本轮只编译打包 x64，未运行测试或 UI 验证；其它翻译目标语言闪退原因不据此宣称已排除。

## 已实现并验证

- Windows 11 x64 / .NET 10 自包含 WinForms；独立命名管道 C++ 推理进程，退出随主程序回收。
- Qwen3-ASR 1.7B BF16（含音频编码 GGUF）、Whisper Turbo、Qwen3 4B Q4_K_M、Hunyuan-MT 7B Q4_K_M：CPU/CUDA 均完成真实推理、取消恢复及三轮加载释放。
- Whisper Tiny/Base/Small：固定 revision、大小与 SHA256；CPU 真实三语种推理、取消恢复和反复加载通过。
- 配置严格校验、原子提交、按角色提交运行选项、旧 x86 配置只读迁移、DPAPI 密钥隔离。
- WebRTC VAD、240ms 预录、智能/固定停顿、预览修订及失效、分块缓存、EOF/停止排空和积压停止；不按25秒强制定稿、不做重叠识别和文本去重。
- 本地翻译逐 token 拉取、ASR 优先、四个等待单元、九目标语言、同语种跳过、两组上下文、旧会话译文回原行。
- HTTP/WS/SSE 模拟服务、连接失败/截断/限流/取消/重定向拒绝；AI 总结/翻译/提问窗口和多服务管理。
- LiveTranslate text/audio 协商，24kHz PCM16，重复过滤、样本拼接、先音频后关联、按原文顺序定稿播放；30秒单段、128MiB内存重播，清空释放。
- Windows 进程级 loopback 实测排除自身播放：自身峰值0.0000305，独立外部进程峰值0.06088，无采集错误。
- 原生工作进程被主动结束时及时报告错误，保留已完成文字；重新加载后继续转录。真实 Whisper Turbo CPU 预热取消后恢复 Tiny，继续识别通过。
- 主窗口、设置窗口冒烟绘制和偏好保存；x86 原有28项回归通过。

Windows 后端150项、桌面协议13项、x86兼容版28项检查通过。

## 本机和数据

Windows 11 x64，Ryzen 7 7800X3D，约32GB RAM，RTX 5060 Ti 16GB，驱动610.88；原生依赖、模型版本与构建参数在 `NATIVE-RUNTIME.md`、`models.lock.json`、`native-verification.json` 中固定。

`quality-verification.json` 对三段固定合成音频计算去标点/大小写后的 CER，以及英文 WER。Qwen 的三个样本 CER 为0、英文 WER为0；CUDA 实时系数约0.04–0.06。该小样本不代表真人、噪声或各口音准确率。Whisper 的繁简和数字写法差异会计入字面错误率，未用语义或数字归一化隐藏差异。

CPU 验证正确性和过载保护，不承诺实时：本机 Qwen 部分样本实时系数约1.15–1.25，Whisper Turbo约2.15–3.19。自动设备回退已通过真实 CPU 推理；明确选择 CUDA 不会静默切换 CPU。

连续识别＋本地翻译运行49分钟，完成293次定稿及293次翻译，无报告错误；按用户要求提前停止，不标记一小时验收通过。记录见 `soak-verification.json`。定稿 `elapsed_ms=0` 可表示复用预览缓存，不能解释为模型推理耗时为0。
