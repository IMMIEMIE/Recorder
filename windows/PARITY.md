# Mac → Windows 完整功能对照

基线提交：`4d69912`（保留开始实施时已存在的 Windows UI 改动）。此表描述目标，不代表已实现。阶段证据见 `PORT-PROGRESS.md`。

| 子系统 | Mac 基线行为 | Windows x64 完成条件 |
|---|---|---|
| 本地 ASR | Qwen3-ASR 1.7B、Whisper Turbo、兼容自定义 ID/目录 | 原生 CPU/CUDA 真实推理、取消/恢复、模型切换 |
| 模型生命周期 | 加载、预热、释放、失败不保存新配置 | ASR/翻译分别提交，失败恢复旧配置 |
| 模型下载 | 可取消、单任务、断点续传、revision、哈希、HF 缓存 | 固定模型清单、下载器模拟服务和离线测试 |
| 分段 | WebRTC VAD mode 2、20ms、240ms 预录 | 相同帧输入产生相同边界 |
| 智能定稿 | 识别反馈，500/1000/1800ms；固定停顿可选 | 相同反馈和音频产生相同事件 |
| 临时识别 | 默认1200ms、最新预览槽、过期结果丢弃 | 不覆盖 final、不在静音中重复请求 |
| 识别缓存 | 完整输入块与最后预览缓存；无新语音复用 | 真实引擎调用次数与共享样例一致 |
| 长句 | 单次模型输入默认18s；不强制定稿，无重叠/去重 | 重复词保留，分块不产生额外用户行 |
| 背压 | 320KB 音频缓冲；6个待处理final时停止 | 不静默丢帧，已有文字保留 |
| 音源 | 麦克风、系统声音、原速文件、EOF/停止排空 | Windows 硬件和文件真实验证，自身播放排除 |
| 本地翻译 | Qwen3 4B、Hunyuan-MT 7B、9目标语言 | 生成、取消和释放真实验证 |
| 翻译规划 | 句子单元、2上下文对、同语种跳过、相同译文隐藏 | 共享样例一致；保留旧 forced_cut 兼容语义 |
| 调度 | finals/load/finish > translation > latest preview | 逐token暂停/恢复，4个待翻译单元上限 |
| 结果归属 | session/segment/unit/revision，迟到译文回旧行 | 重启、乱序、重复及清空历史后不串行 |
| HTTP ASR | WAV multipart，段/预览共享识别流程 | 模拟服务和真实服务验证 |
| 千问流式 | 固定端点/模型，100ms PCM，finish后等待尾句 | 模拟协议和真实账号验证；不进入本地分段 |
| API 翻译 | 使用已保存服务，流式结果、取消 | 与本地翻译独立，失败保留原文 |
| AI | 总结/翻译/自定义提问、SSE、取消/复制/保存 | 可用窗口与多服务管理，故障可恢复 |
| LiveTranslate | 独立模式，配置/密钥隔离，原译文配对 | 切换关闭其他会话，文本和音频事件验证 |
| 译音 | 24kHz PCM16，流式/定稿后播放，音量 | 重复/碎片/乱序/超时/设备变化测试 |
| 重播 | 内存缓存128MiB，单句30s，跨录音保留 | 清空历史释放，不落盘 |
| 设置与密钥 | 配置严格校验、原子保存、Keychain | Windows DPAPI、独立x64目录、旧设置只读迁移 |
| 展示与导出 | partial/final/translation、字幕、TXT/SRT | 完整入口、状态反馈、偏好保存 |

## 数据约束

本地加载/识别/翻译不联网；模型显式下载；API/实时服务仅在用户启用时请求。音频、原文、译文、译音不自动落盘。API 密钥不传给 C++ 推理进程。安装包不包含模型。

## 同步规则

行为变更必须更新此表及共享样例；双方执行通过才标记同步。模型数值验证独立记录，不用逐字相等替代 CER/WER、语义与关键数字检查。Mac 真实运行与真实云账号未验证时明确保留待验收状态。
